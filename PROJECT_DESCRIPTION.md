# User Management System

## Описание проекта

User Management System представляет собой простую систему управления пользователями.

Система хранит данные пользователей в памяти и предоставляет базовые операции по управлению коллекцией пользователей.

---

# Структура проекта

```text
src/

├── user.py
└── user_manager.py
```

---

# Модуль user.py

Содержит класс User.

## Конструктор

При создании объекта необходимо указать:

```python
user_id
name
age
email
```

Пример:

```python
user = User(
    user_id=1,
    name="Alex",
    age=25,
    email="alex@test.com"
)
```

---

## is_adult()

Определяет, является ли пользователь совершеннолетним.

Правило:

```python
age >= 18
```

Метод возвращает:

```python
True
```

или

```python
False
```

---

## to_dict()

Возвращает данные пользователя в виде словаря.

Пример результата:

```python
{
    "id": 1,
    "name": "Alex",
    "age": 25,
    "email": "alex@test.com"
}
```

# Модуль user_manager.py

Содержит класс UserManager.

Класс предназначен для хранения и управления коллекцией пользователей.

---

## add_user(user)

Добавляет пользователя в систему.

Перед добавлением выполняются проверки.

### Проверка user_id

Требования:

```python
тип int
уникальное значение
```

Исключения:

```python
TypeError
ValueError
```

---

### Проверка name

Требования:

```python
тип str
не менее двух символов
```

Исключения:

```python
TypeError
ValueError
```

---

### Проверка age

Требования:

```python
тип int
значение от 0 до 120 включительно
```

Исключения:

```python
TypeError
ValueError
```

---

### Проверка email

Требования:

```python
тип str
наличие символа "@"
```

Исключения:

```python
TypeError
ValueError
```

---

## get_user(user_id)

Возвращает пользователя по идентификатору.

Если пользователь отсутствует:

```python
None
```

---

## remove_user(user_id)

Удаляет пользователя по идентификатору.

Если пользователь отсутствует:

```python
ValueError
```

---

## get_all_users()

Возвращает список всех пользователей.

---

## count_users()

Возвращает количество пользователей в системе.
